# Vibe-Detect

---

## What is it?

A simple rulebased no dependencies Ai code detector.

---

## How does it work?

It works by checking if any words match any classic AI words (listed classicAIWords.vd).
It also checks by counting how many comments there are in a code, ik not the best way but hey it works pretty well.

---

## Why?

It's mostly a fun little experiment (which took me around 2 weeks to do)
But it can also be used by people who suspect a specific piece of code is AI generated and yea some maintainers might like it.
